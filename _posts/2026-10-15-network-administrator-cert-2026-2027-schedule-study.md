> 일정·응시료·합격 기준은 전부 시행기관인 **(사)한국정보통신자격협회(ICQA)**의 [네트워크관리사 안내 페이지](https://www.icqa.or.kr/cn/page/network)에서 2026-10-15 에 직접 확인한 값이다.
> **2027년 일정은 아직 공고되지 않았다.** 아래 2027년 부분은 "2026년 패턴을 보면 이쯤일 것"이라는 추정이고, 그렇게 표시해 둔다. 접수 전에 반드시 공식 공고를 다시 확인하자.

## TL;DR

- **2급**은 국가공인 민간자격이고 응시 제한이 없다. 1년에 4번, 필기 → 실기 순서로 본다.
- **1급**은 등록(비공인) 민간자격이고 응시 자격이 있다. 1년에 2번, 서울·대전에서만 본다.
- 합격선은 필기·실기 모두 **100점 만점에 60점 이상**이다.
- 2026년에 남은 일정은 **1급 제2회 실기**(접수 10/27~10/30, 시험 11/29)와 **2급 제4회 실기**(접수 11/3~11/6, 시험 12/6)다. 실기는 해당 등급 필기 합격자만 볼 수 있다.
- 공부는 **서브네팅 손계산 → 프로토콜·포트 암기 → Windows Server/Linux 서버 실습 → 라우터 명령 실습** 순서를 추천한다. ICQA 가 라우터 에뮬레이터와 모의고사 프로그램, 최근 기출을 공식 자료실에 올려 두었다.

## 1. 자격 개요

| | 2급 | 1급 |
|---|---|---|
| 자격 종류 | 공인민간자격 (2002-01-10 국가공인) | 등록(비공인) 민간자격 |
| 공인·등록 번호 | 등록 2008-0212 / 공인 과학기술정보통신부 제2023-02호 | 등록 2008-0212 |
| 필기 응시자격 | 제한 없음 | 아래 중 하나 이상 (아래 설명) |
| 실기 응시자격 | 해당 등급 필기 합격일부터 2년 이내 | 해당 등급 필기 합격일부터 2년 이내 |

**1급 필기 응시자격** (공식 페이지 원문 요약, 하나 이상 해당):
- ICQA 가 시행하는 같은 종목 2급 자격 소지자
- 전기·전자·통신·정보처리 분야 국가기술자격 중 기술사·기사·산업기사 소지자, 또는 기능사를 딴 뒤 같은 직무 분야에서 2년 이상 실무에 종사한 사람
- IT 관련 사업장에서 5년 이상 종사한 사람

현실적으로는 **2급을 먼저 따고 1급으로 가는 경로**가 가장 흔하다.

2026년 11월 1일 시험 접수 공고는 시험 환경을 **Windows Server 2022** 로 명시했다([공지 639](https://www.icqa.or.kr/cn/board/notice/639)).

## 4. 2027년 일정 — 아직 공고 전 (추정)

2026-10-15 기준으로 ICQA 안내 페이지의 일정표에는 2026년 행만 있고, 공지사항에도 2027년 일정 공고는 없다.

2026년 패턴(2급은 2·5·8·11월 필기, 1급은 4·10월 필기)이 그대로 이어진다고 **가정하면**, 지금 처음 시작하는 사람의 다음 기회는 이렇게 된다:

- **2급 2027년 제1회 필기**: 1월 초 접수, 2월 초 시험 정도로 예상 (**추정**)
- **1급 2027년 제1회 필기**: 3월 접수, 4월 시험 정도로 예상 (**추정**)

정확한 날짜는 ICQA 가 공고를 올리면 이 글을 고치겠다. 2026년 일정은 ICQA 가 구글 캘린더로도 제공했다([공지 610](https://www.icqa.or.kr/cn/board/notice/610)). 2027년에도 같은 방식이면 캘린더 구독이 가장 편하다.

## 5. 공부 방법

### 5-1. 순서: 손계산 → 암기 → 서버 → 라우터

**① 서브네팅을 손으로 (1~2주)**
TCP/IP 과목의 핵심이고 실기에서도 계속 쓰인다. 계산기 없이 아래를 1분 안에 풀 수 있을 때까지 반복한다.
- `/26` 이면 서브넷 몇 개, 호스트 몇 개? 네트워크·브로드캐스트 주소는?
- 사설 주소 대역 세 개(10/8, 172.16/12, 192.168/16)는 [RFC 1918](https://www.rfc-editor.org/rfc/rfc1918) 이 정의한다.
- 클래스 개념보다 CIDR([RFC 4632](https://www.rfc-editor.org/rfc/rfc4632))로 생각하는 습관을 들이면 VLSM 문제가 쉬워진다.

**② 프로토콜과 헤더 (1~2주)**
- IP·TCP·UDP 헤더 필드는 원 사양으로 한 번 보는 게 가장 빠르다: [RFC 791 (IP)](https://www.rfc-editor.org/rfc/rfc791), [RFC 9293 (TCP)](https://www.rfc-editor.org/rfc/rfc9293), [RFC 768 (UDP)](https://www.rfc-editor.org/rfc/rfc768). TCP 3-way handshake·상태 전이·플래그가 자주 나오는 영역이다.
- 잘 알려진 포트(FTP, SSH, Telnet, SMTP, DNS, HTTP/HTTPS, SNMP 등)와 OSI 7계층별 장비(허브·스위치·라우터·L4)는 표로 만들어 외운다.
- 패킷 분석 문제는 Wireshark 로 내 PC 의 DNS 질의·TCP 연결을 직접 떠 보고, 필드를 하나씩 대조하면 감이 빨리 온다.

**③ 서버 실습 — Windows Server + Linux (2~3주)**
NOS 과목과 실기 작업형의 큰 비중이다. **눈으로 보는 공부로는 안 된다.**
- 가상머신에 Windows Server 2022 를 올려서 Active Directory 도메인 구성, 사용자·그룹·권한, DNS 영역, IIS 사이트, FTP, 공유 폴더 권한을 직접 만들어 본다. AD DS 개념은 [Microsoft Learn 개요](https://learn.microsoft.com/en-us/windows-server/identity/ad-ds/get-started/virtual-dc/active-directory-domain-services-overview)가 공식 설명이다.
- Linux 는 사용자·권한(`chmod`/`chown`), 프로세스, 네트워크 설정, 서비스 관리 명령을 손에 익힌다.

**④ 라우터 명령 실습 (1주)**
ICQA 자료실에 수험생용 [Router Emulator 프로그램](https://www.icqa.or.kr/cn/board/dataroom/21)과 네트워크관리사 실습용 에뮬레이터, ICQA 모의고사 예제 프로그램이 올라와 있다. 실기 화면에 익숙해지는 데는 공식 도구가 가장 정확하다.
인터페이스 IP 설정, 호스트명, 라우팅(정적·동적), 설정 저장 같은 기본 명령을 막힘 없이 칠 수 있게 반복한다.

**⑤ 기출로 마무리 (1주)**
ICQA 자료실에 최근 필기 기출이 공식으로 올라와 있다 — [2026년 제3회 2급 필기](https://www.icqa.or.kr/cn/board/dataroom/256), [2026년 제1회 1급 필기](https://www.icqa.or.kr/cn/board/dataroom/240).
2026-10-15 기준 자료실에 공개된 기출은 등급별로 이 한 회차씩이고, 실기 기출은 없다. 그래서 기출만 돌리는 공부로는 부족하고, ①~④가 바탕이 돼야 한다.

### 5-2. 기간별 계획 예시 (2급, 직장인 기준)

| 기간 | 할 일 |
|---|---|
| 1~2주 | 서브네팅 손계산, OSI·TCP/IP 계층, 장비 구분 |
| 3~4주 | 프로토콜·헤더·포트, Wireshark 로 패킷 보기 |
| 5~6주 | Windows Server 2022 가상머신 실습 (AD·DNS·IIS·FTP·권한) |
| 7주 | Linux 명령어, 라우터 에뮬레이터 |
| 8주 | 공식 기출과 모의고사 프로그램, 오답 정리 |

필기와 실기 사이가 약 한 달(필기 발표 → 실기 시험)이라, **필기 공부 단계에서 이미 실습을 같이 해 두는 게** 실기를 한 번에 붙는 요령이다.

### 5-3. 1급으로 갈 때 추가로 볼 것

1급은 필기에 **정보보호개론**이 추가된다. Windows/Linux 서버 보안 설정, 네트워크 보안(방화벽·IDS/IPS·VPN 개념), 암호화(대칭·비대칭·해시)를 따로 공부해야 한다.
실기 시간도 100분으로 길다. 2급 실습 환경을 그대로 확장해서 보안 설정까지 해 보는 게 효율적이다.

## 6. 접수 전 체크리스트

- [ ] 공식 일정표를 다시 확인했다 ([ICQA 네트워크관리사](https://www.icqa.or.kr/cn/page/network))
- [ ] (1급) 응시자격 증빙 서류를 준비했다 — 경력(재직)증명서 또는 해당 자격증
- [ ] 필기 발표일 = 실기 접수 시작일이라는 걸 달력에 표시했다
- [ ] 실습 환경(Windows Server 가상머신, ICQA 에뮬레이터)을 미리 설치해 뒀다
- [ ] 시험 지역 인원이 20명 미만이면 지역이 바뀌거나 취소될 수 있다는 점을 알고 있다
